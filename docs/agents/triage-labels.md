# Triage labels

| Role              | In Linear               |
| ----------------- | ----------------------- |
| `needs-triage`    | state `Triage`          |
| `needs-info`      | label `needs-info`      |
| `ready-for-agent` | label `ready-for-agent` |
| `ready-for-human` | label `ready-for-human` |
| `wontfix`         | state `Canceled`        |

Triaging out of `Triage` moves the issue to `Backlog` or `Todo`. Issue type is a separate label: `Bug`, `Feature` or `Improvement`.

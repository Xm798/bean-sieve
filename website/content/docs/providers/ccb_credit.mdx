## 账单下载方式

建设银行信用卡每月把电子账单发到预留的邮箱。还没开通邮件账单时，到建设银行的信用卡渠道设置账单邮箱，具体入口以银行说明为准。

收到账单后，在邮件客户端把整封邮件保存为 `.eml` 文件：

| 客户端 | 操作 |
| :--- | :--- |
| Gmail 网页版 | 打开邮件，点右上角「⋮ → 下载邮件」 |
| Apple Mail | 把邮件从列表拖到访达 |
| Thunderbird | 选中邮件，「文件 → 另存为 → 文件」 |

只复制正文或另存为 HTML 得到的文件无法解析。

某个月没收到邮件时，可以在建设银行手机银行里查询并下载这个月的电子账单 PDF（龙卡信用卡对账单），直接传入即可。

## 支持的文件格式与识别方式

<ProviderFacts id="ccb_credit" />

文件名里没有「建设银行」时，Bean-Sieve 会解码邮件标题和正文，或读取 PDF 第一页的文字，在里面找「中国建设银行信用卡」或「龙卡信用卡对账单」。

两种格式的交易都取自「【交易明细】」表格，每行有交易日、银行记账日、卡号后四位、交易描述、交易币种与金额、结算币种与金额。日期是 `YYYY-MM-DD`，取交易日。金额取结算币种那一列，负数是还款或退款。对账范围取账单周期，如 `2030/03/01-2030/03/31`。

## 邮件与 PDF 同时传入

同一账单周期的邮件和 PDF 内容相同，一起传入时每张卡只采用邮件，PDF 里这张卡的交易不用，避免重复入账。终端输出的 Statement selection 会列出采用和丢弃的文件；两份的交易笔数或金额合计对不上时，还会给出一条 Mismatch 提示。

- 是否重叠按印出的账单周期判断，每张卡分开判断。
- 同一周期有两份 PDF 时，命令行里靠前的那份生效。
- 加 `--keep-overlap` 跳过这一步，所有文件的交易都保留。

## 配置示例

建设银行信用卡按卡管理：各卡账单日合并为同一天，但每张卡独立还款，账本里通常每张卡建一个账户。一份账单里有多张卡时，每行按自己的卡号后四位找账户。`accounts` 的键是卡号后四位：

```yaml title="bean-sieve.yaml" config
providers:
  ccb_credit:
    accounts:
      "1234": Liabilities:CreditCard:CCB:1234
      "5678": Liabilities:CreditCard:CCB:5678

rules:
  - description: "还款"
    contra_account: Assets:Bank:Checking
```

交易描述写入描述，收款方为空，可以用规则的 `target_payee` 补上。

## 解析出的元数据字段

| 字段 | 来源列 | 说明 |
| :--- | :--- | :--- |
| `card_last4` | 卡号后四位 | |
| `original_amount` | 交易币/金额 | 仅在交易币种与结算币种不同时出现 |
| `original_currency` | 交易币/金额 | 与 `original_amount` 一起出现 |

默认输出。在 `defaults.output_metadata` 里列出字段名后，只输出列出的字段。

## 已知限制

- 卡号后四位一栏有时印成 `1234/扫码` 或 `1234/5678`，这时 `card_last4` 原样保留整个单元格：`accounts` 里要用同样的写法作键才能找到账户，邮件与 PDF 的取舍也按这个值分开判断。以后会改成只取前四位。
- 账单中出现 `accounts` 没有列出的卡号时，这些交易的账户输出为 `Assets:FIXME`。

## 输出样例

仓库的 [`examples/ccb_credit/`](https://github.com/Xm798/bean-sieve/tree/master/examples/ccb_credit) 目录是一组虚构数据，也是端到端测试的输入。在该目录下运行：

```bash
bean-sieve reconcile 中国建设银行信用卡对账单2030年02月.pdf 中国建设银行信用卡电子账单.eml -c bean-sieve.yaml -l ledger.bean -o pending.bean
```

2 月只有 PDF 账单，其中一笔港币消费按人民币结算金额入账，原币金额记在 `original_amount` 里。账本里已有的 3 月 3 日消费被匹配，不再输出；规则 `年费` 同时命中了年费和「积分兑换年费」，两笔互相抵消；账本里 3 月 25 日那笔在账单里找不到，被列为 Extra。

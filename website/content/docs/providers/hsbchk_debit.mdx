## 账单下载方式

登录 [HSBC HK Online Banking](https://www.hsbc.com.hk/)，在储蓄账户的交易记录页点「Download」，格式选 CSV。导出的文件名是 `TransactionHistory.csv`。

## 支持的文件格式与识别方式

<ProviderFacts id="hsbchk_debit" />

汇丰香港信用卡（`hsbchk_credit`）导出的文件同名，Bean-Sieve 按表头区分：储蓄账户的表头以 `Date,Description,Billing amount,Billing currency,Balance` 开头，信用卡的以 `Transaction date,Post date` 开头。

文件有 6 列：`Date`、`Description`、`Billing amount`、`Billing currency`、`Balance`、`Balance currency`。日期格式是 `日/月/年`。`Billing amount` 正数是入账、负数是支出，币种取 `Billing currency`，为空时按港币处理。

描述是 `Description` 原文。描述以 `HC` 加一串数字或 `NET-` 加一串数字这类参考编号开头时，编号记为 `order_id`。

## 配置示例

```yaml title="bean-sieve.yaml" config
providers:
  hsbchk_debit:
    accounts:
      "default": Assets:Bank:HSBCHK:HKD
    balance: true

rules:
  - description: "^NET-"
    contra_account: Liabilities:CreditCard:HSBCHK
  - description: "CREDIT INTEREST"
    contra_account: Income:Bank:Interest
```

CSV 里没有账号，所以 `accounts` 只写一项，所有交易都记到这个账户，它也是 Extra 的检查范围。键可以随意取，示例用的是 `"default"`；写成 4 位数字时，它会作为每行的 `card_last4`。

加 `balance: true` 会在输出末尾追加一条 `balance` 断言，金额和币种取最后一行的 `Balance` 和 `Balance currency`，日期是该行日期的次日。

CSV 没有交易对方列，收款方为空，规则只能按描述匹配，要写收款方就在规则里用 `target_payee`。

## 解析出的元数据字段

| 字段 | 来源列 | 说明 |
| :--- | :--- | :--- |
| `order_id` | Description | 开头的参考编号，有时才出现 |
| `balance` | Balance | 保留原文的千位分隔符 |
| `balance_currency` | Balance currency | 仅在与交易币种不同时出现 |

默认全部输出，空值会被略去。要只输出其中几项，在 `defaults.output_metadata` 里列出字段名；`providers.hsbchk_debit.output_metadata` 列出的字段会追加到全局列表上。

## 已知限制

- `accounts` 写了多项时，Bean-Sieve 分不出交易属于哪个账户，只打印一条警告，银行一侧的 posting 输出为 `Assets:FIXME`，也不生成余额断言。
- 没有交易对方，收款方只能靠规则补上。
- 对账范围是第一笔到最后一笔交易的日期，前后各放宽 `date_tolerance` 天。

## 输出样例

仓库的 [`examples/hsbchk_debit/`](https://github.com/Xm798/bean-sieve/tree/master/examples/hsbchk_debit) 目录是一组虚构数据，也是端到端测试的输入。在该目录下运行：

```bash
bean-sieve reconcile TransactionHistory.csv -c bean-sieve.yaml -l ledger.bean -o pending.bean
```

配置里唯一的 `accounts` 项让所有行都记到 `Assets:Bank:HSBCHK:HKD`，输出末尾按 10 月 31 日的余额生成了 11 月 1 日的余额断言。账本里已有的 10 月 18 日晚餐被匹配，不再输出；10 月 1 日和 3 日的交易带出了 `order_id`；账本里 10 月 22 日那笔在账单里找不到，被列为 Extra。

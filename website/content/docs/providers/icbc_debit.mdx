## 账单下载方式

登录[工商银行个人网上银行](https://mybank.icbc.com.cn/icbc/newperbank/perbank3/frame/frame_index.jsp)，查询借记卡明细后下载 CSV 文件。网银需要安装安全控件，macOS 上要用 Safari。

导出的文件名形如 `hisdetail20301130.csv`。Bean-Sieve 只靠文件名里的 `hisdetail` 识别账单，改过名的文件要用 `-p icbc_debit` 指定。

## 支持的文件格式与识别方式

<ProviderFacts id="icbc_debit" />

文件是带 BOM 的 UTF-8 CSV，前几行是卡号和子账户信息，卡号后四位从打码的卡号里取，接着是表头和交易，末尾的「人民币合计」行会被跳过。文件按时间倒序排列，Bean-Sieve 读入后改为正序。

金额取「记账金额(收入)」和「记账金额(支出)」两列，千位分隔符会被去掉。描述由「摘要」「交易详情」「交易场所」拼成，收款方取「对方户名」。

## 配置示例

```yaml title="bean-sieve.yaml" config
providers:
  icbc_debit:
    accounts:
      "1234": Assets:Bank:ICBC

rules:
  - description: "代发工资"
    contra_account: Income:Salary
  - description: "水电燃气"
    contra_account: Expenses:Housing:Utilities
```

`accounts` 的键是卡号后四位。网银每次导出一张卡的明细，有几张卡就列几项；对账时只把这份文件那张卡对应的账户纳入 Extra 检查。

加 `balance: true` 会在输出末尾追加一条 `balance` 断言，金额取这张卡最后一笔交易后的余额，日期是该笔交易的次日。

## 解析出的元数据字段

| 字段 | 来源列 | 说明 |
| :--- | :--- | :--- |
| `summary` | 摘要 | |
| `detail` | 交易详情 | |
| `location` | 交易场所 | |
| `balance` | 余额 | 已去掉千位分隔符 |
| `counterparty_account` | 对方账户 | |

默认全部输出，空值会被略去。要只输出其中几项，在 `defaults.output_metadata` 里列出字段名；`providers.icbc_debit.output_metadata` 列出的字段会追加到全局列表上。

## 已知限制

- 明细只有日期，没有交易时间。
- 金额一律按人民币处理，「记账币种」列不读取。
- 对账范围是这张卡第一笔到最后一笔交易的日期，账本里晚于最后一笔交易的条目不会报 Extra。
- 文件名不含 `hisdetail` 时不会被自动识别。

## 输出样例

仓库的 [`examples/icbc_debit/`](https://github.com/Xm798/bean-sieve/tree/master/examples/icbc_debit) 目录是一组虚构数据，也是端到端测试的输入。在该目录下运行：

```bash
bean-sieve reconcile hisdetail20301130.csv -c bean-sieve.yaml -l ledger.bean -o pending.bean
```

账本里已有的 11 月 26 日晚餐被匹配，不再输出；明细没有交易时间，输出里也就没有 `time`；账本里 11 月 18 日那笔在账单里找不到，被列为 Extra。

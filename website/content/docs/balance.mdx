title: 余额断言
description: 对账后为借记卡账户生成 balance 指令，校验账本余额

---

借记卡账单通常带余额列。打开 `balance` 后，Bean-Sieve 会在输出末尾为每个账户追加一条 Beancount `balance` 指令，用 `bean-check` 就能核对账本余额和银行是否一致。

## 开启

按数据源配置，默认关闭：

```yaml title="bean-sieve.yaml" config
providers:
  pab_debit:
    accounts:
      "1029": Assets:Bank:PAB:1029
    balance: true
```

只有账单里带余额的数据源才会生成断言。数据源页面的元数据字段表里列有 `balance` 的就支持。

## 生成规则

- 每个账户和余额币种各生成一条，金额取账单里最后入账的那笔交易后的余额。交易带入账日期（如过账日）时按入账日期排先后，否则按交易日期。
- 日期是账单结束日的次日；账单没有给出起止日期时，用最后那笔交易入账日期的次日。Beancount 的 `balance` 断言检查的是当天开始前的余额，所以要放在次日。
- 没有匹配到账户的交易不参与。

输出示例：

```beancount
2030-04-01 balance Assets:Bank:PAB:1029  12345.67 CNY
```
